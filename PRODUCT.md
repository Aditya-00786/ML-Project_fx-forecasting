# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Two forms built from the same saved results: a self-contained static HTML file generated by a Python script (`reports/dashboard.html`), and a Streamlit app run locally. Both read only the tables and predictions the pipeline writes; neither runs a model.

## Users

Three audiences, each with its own view:

- **The course professor, evaluating the project:** checks the answers to the five research questions and whether each claim is backed by a significance test and a saved table.
- **The six-member team, exploring results:** digs into any pair, model, task or period to find the stories for the final report and slides.
- **A live audience at the final presentation:** sees a few large, legible views clicked through while a team member talks.

## Product Purpose

The results of "Regime-aware learning of returns and volatility in G10 FX" (BITS F464 Machine Learning) in one place: data quality, baselines, market regimes and currency factors, classical and neural models, the trading backtest and Value at Risk, the extensions and the extra pairs. Success means a reader can answer "what is predictable, when, and is it worth money?" without opening a notebook, and can trace every number to its source table.

## Positioning

An honest research results browser, not a trading product: negative findings (returns and direction are unpredictable; no direction signal pays after costs) are reported as plainly as the positive ones (machine learning beats HAR-RV on one-day volatility).

## Operating Context

- Opened from the repository on a laptop, offline; shown on a projector during the presentation.
- Built from `reports/tables/*.csv` and `reports/predictions/*.parquet`, rebuilt with one command after the pipeline runs.
- Sits beside the notebooks (`notebooks/01`–`09`), the final LaTeX report and the slides.

## Capabilities and Constraints

- Free tools only; no paid services or hosting.
- Works offline: the static file must not need a network connection.
- Covers seven core pairs (EUR/USD, GBP/USD, USD/JPY, USD/CHF, AUD/USD, USD/CAD, NZD/USD), two extra pairs (EUR/GBP, USD/INR), three tasks (volatility, direction, returns), test period 2012–2026.
- Terminology from the project: QLIKE, HAR-RV, Diebold–Mariano, Pesaran–Timmermann, walk-forward, regimes (calm/turbulent), carry, volatility targeting, Value at Risk.

## Evidence on Hand

All results already exist as CSV tables and Parquet predictions in `reports/`, with figures in `reports/figures/`. Nothing is to be invented: every number shown comes from those files.

## Product Principles

1. Every claim sits next to its evidence: the metric, the test and the source table.
2. Negative results are results; show them with the same weight.
3. One question per view; the audience decides the depth.
4. The same numbers everywhere: the dashboard, notebooks and report never disagree.
